# Rep Counter Portfolio

Dark, glassmorphism portfolio with a browser-based AI fitness coach. It counts push-ups, squats, lunges, curls, shoulder presses, jumping jacks and plank holds from your webcam using MediaPipe Pose. Everything runs locally in the browser.

Live: https://portfolio-amber-five-45.vercel.app

## Run locally

    npx serve .

The camera needs HTTPS or localhost.
